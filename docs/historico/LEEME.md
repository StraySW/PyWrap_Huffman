# Material histórico

Esta carpeta conserva documentación, capturas y pruebas de versiones anteriores. No es necesario ejecutar ni explicar este material para usar la versión actual. Las pruebas archivadas dependen de APIs antiguas y no se mantienen.

La guía vigente es `../../README.md` y la explicación breve está en `../EXPLICACION.md`. Las referencias a módulos eliminados, estadísticas antiguas o cantidades de pruebas pertenecen a esas versiones anteriores.
